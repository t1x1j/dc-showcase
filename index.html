No index server, no host, no API key. Every step is an eth_call against public state.

01

Walk the registry

The Search contract returns every Tag contract. Each Tag returns its Data contracts.

02

Read metadata

Each Data contract reports its MIME type, chunk count, and part order, naming siblings for multi-part payloads.

03

Pull the chunks

Bytes are fetched from contract storage via getData, joined client-side, and fingerprinted with SHA-256.
